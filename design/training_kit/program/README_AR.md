# برنامج دفع/سحب/أرجل + مجسّم التمارين (تجربة)

- `ppl_program.json`: 36 تمريناً في 6 أيام (مجموعات، تكرارات، راحة، إيقاع، إرشادات). مسودة تجريبية تحتاج مراجعة مختص.
- `poses_gen.json` (= `ppl_poses.json`): أوضاع المجسّم لكل تمرين (وضع بداية `a` ووضع نهاية `b`، و`c` للاندفاع) + الأدوات والكاميرا والتثبيت. تُولَّد، لا تُكتب يدوياً.
- `ppl_artifact.template.html` + `tools/build_ppl_artifact.py`: يبنيان صفحة العرض `review/ppl_mannequin_demo.html` (نفسها المنشورة كـArtifact).
- أدوات التأليف في `tools/`:
  - `mq_fit.js`: يحل زوايا المفاصل من قيود فضائية (يد على بار، قدم على الأرض) بالبحث المحلي فوق FK المجسّم الحقيقي، ويقدّر مركز الكتلة.
  - `mq_author.js`: مواصفة كل تمرين (قيود لا زوايا خام) → `poses_gen.json`. شغّل `node tools/mq_author.js squat,bench_press` أو `*`.
  - `mq_harness.js`: شبكة لقطات (أمام/جانب) لكل وضع للمراجعة بالعين مع تقرير الأرض والتصادم.
- ملاحظة: `delivery/mannequin/mannequin.js` هو ملف Claude Design كما استُلم، و`mannequin.css` كتبته أنا (ألوان الثيمات الثلاثة) لأن ملفه لم يصل.
