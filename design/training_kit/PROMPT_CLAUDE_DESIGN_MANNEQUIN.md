# برومبت Claude Design — المجسّم البشري ثلاثي الأبعاد لتمارين «حصتي»

> الصق ما تحت الخط في Claude Design، وأرفق `design/hissati_themes_kit` (الثيمات والشعار) وهذا الملف. بعد التسليم يحرّك Claude Code (المبرمج) المجسّم لكل تمرين، فالمطلوب هنا **المجسّم وهيكله وواجهة تحريكه وجودة مظهره**، لا التمارين نفسها.

---

## الهدف
مجسّم (مانيكان) بشري ثلاثي الأبعاد **محايد الجنس ومحتشم**، أنيق وبسيط، يُعرض داخل تطبيق «حصتي» (عربي RTL، جوال أولاً، يعمل بلا إنترنت)، ويؤدي أي تمرين عبر **أوضاع مفاصل** (زوايا فقط) يكتبها المبرمج لاحقاً. الأهم: **دقة الهيكل وسهولة تحريكه برمجياً** ثم جمال المظهر.

## قيود تقنية صارمة (سياسة الأمان CSP في التطبيق)
- **بلا أي مكتبة خارجية** (لا Three.js ولا غيره) ولا خطوط أو صور أو سكربتات من الإنترنت ولا `blob:`.
- ملف JavaScript واحد عادي (ES2017) ≤ 40 كيلوبايت غير مضغوط، يرسم على `<canvas>` (2D مع إسقاط منظوري يدوي، أو WebGL إن كان بلا مكتبة وبلا تحميل خارجي، مع **بديل canvas 2D** عند غياب WebGL).
- أداء: 60 إطاراً على جوال متوسط، وإيقاف الرسم عند خروج العنصر من الشاشة أو إخفاء الصفحة. دقة العرض تتكيف مع `devicePixelRatio` (حد أقصى 2).
- `prefers-reduced-motion`: يعرض وضع البداية ثابتاً وزرّ «شغّل» يدوياً.
- لا تغيّر شيئاً من بنية التطبيق؛ يُسلَّم كوحدة مستقلة `mannequin.js` + `mannequin.css`.

## 1) الهيكل (Rig) — الجزء الأهم
**أسماء المفاصل ثابتة (لا تغيّرها):**
`pelvis` (الجذر)، `spine1`، `spine2`، `chest`، `neck`، `head`،
`shoulderL/R`، `elbowL/R`، `wristL/R`،
`hipL/R`، `kneeL/R`، `ankleL/R`، `toeL/R`.
- شجرة هرمية واضحة: pelvis → (spine1 → spine2 → chest → (neck → head) | shoulder → elbow → wrist) | (hip → knee → ankle → toe).
- **أطوال عظام بنسب حقيقية** لقامة قياسية 170 سم، ككائن `RIG.bones` قابل للتحجيم (مثلاً `setHeight(cm)` يغيّر النسبة كلها) مع إمكانية ضبط عرض الكتف/الحوض (`build: 'slim'|'medium'|'strong'`).
- **كل مفصل له درجات حرية بحدود تشريحية** في `RIG.limits` (بالدرجات). مثال: الركبة انثناء فقط 0..145، المرفق 0..150، الورك انثناء/تبعيد/دوران، الكتف 3 محاور، العمود الفقري 3 محاور موزعة على spine1/spine2/chest. القيم التي تتجاوز الحد **تُقصّ (clamp)** مع تحذير في وضع التطوير `Mannequin.debug=true`.
- **اتفاقية المحاور مكتوبة وموثّقة** (أي محور = انثناء/تبعيد/دوران، وإشارة الموجب)، متناظرة بين اليمين واليسار بحيث إن إعطاء الزوايا نفسها لـ L وR يحرك الجانبين **حركة مرآة** لا حركة متطابقة (وثّق ذلك بمثال).
- **اتجاه المحاور:** الأمام +Z، الأعلى +Y، اليمين +X (وثّقه). مجسّم الإحداثيات بالمتر، الأرض عند Y=0.

## 2) واجهة البرمجة (API) — مطلوبة حرفياً
```js
const m = Mannequin.create(canvas, { theme: 'classic'|'rose'|'pulse', build: 'medium', height: 170 });
m.setPose({ pelvis:{pos:[0,0.95,0], rx:0, ry:0, rz:0}, kneeL:{x:90}, hipL:{x:80, z:5}, ... }); // أوضاع جزئية تُدمج فوق الوضع المحايد
m.getPose();
m.animate({ keys: [ {t:0, pose:{...}}, {t:1.6, pose:{...}}, {t:2.4, pose:{...}} ], loop:true, ease:'inOut'|'linear'|'spring', speed:1 });
m.play(); m.pause(); m.seek(t); m.setSpeed(0.5);
m.camera({ yaw:35, pitch:10, dist:3, preset:'front'|'side'|'back'|'three-quarter', orbit:true }); // السحب بالإصبع يدير الكاميرا
m.highlight(['quadsL','quadsR','glutes'], {pulse:true});           // أسماء المناطق أدناه
m.props([{ type:'floor'|'mat'|'bench'|'chair'|'dumbbell'|'band'|'wall'|'box', ... }]);
m.setTheme('rose'); m.resize(); m.destroy();
m.on('frame', t => ...); // لأعداد التكرار
m.snapshot()  // يعيد dataURL (للاختبارات واللقطات)
Mannequin.neutral // وضع الوقوف المحايد
```
- **IK مبسّط للقدمين:** خيار `pinFeet:true` يثبّت الكاحلين على الأرض ويعوّض ارتفاع الحوض تلقائياً حتى لا تطفو القدمان أو تخترق الأرض (مهم لكل تمارين الأرضية والقرفصاء). وخيار `pinHands` للضغط/البلانك.
- **تحقق ذاتي:** دالة `m.validatePose(pose)` تعيد قائمة مشاكل (تجاوز حدود، اختراق أرض، تقاطع أطراف).

## 3) المظهر
- أسلوب **مانيكان ناعم مستقبلي أنيق** (أعضاء كبسولية مستمرة الأسطح، مفاصل ظاهرة بلطف)، **ليس واقعياً مخيفاً** ولا كرتونياً طفولياً. وجه بلا ملامح أو بملامح مجرّدة جداً.
- إضاءة من مصدر واحد ثابت مع ظل أرضي ناعم وتظليل (Lambert + rim light)، وظل على الأرض يعطي الإحساس بالعمق والتلامس.
- **ثلاثة ثيمات:** الحالي (زجاجي كحلي مع لمسة نعناعية)، «وردة» (كريمي/وردي ترابي)، «نبض» (داكن مع لون الفعل الحيوي). الألوان تُقرأ من متغيرات CSS `--hx-*` الموجودة في `themes.css` ولا تُكتب ثابتة.
- **تظليل العضلات المستهدفة** بلون ثانوي متوهج بلطف بدون الاعتماد على اللون وحده (نبض + ملصق نصي صغير يظهر عند اللمس).
- مناطق العضلات (أسماء ثابتة): `neck, traps, delts, chest, lats, upperBack, lowerBack, biceps, triceps, forearms, abs, obliques, glutes, quads, hamstrings, adductors, calves`، مع يمين/يسار حيث ينطبق (`quadsL`/`quadsR`…).
- أدوات التمرين تُرسم بنفس الأسلوب (أشكال بسيطة): بساط، مقعد، كرسي، دمبل، شريط مطاطي ممتد بين اليدين/القدمين مع تمدّد مرئي، حائط، صندوق.

## 4) حالات وإتاحة
- حالات: تحميل، خطأ WebGL/بديل 2D، متوقف، يعمل.
- لوحة أدوات اختيارية صغيرة: زوايا الكاميرا (أمام/جانب/خلف)، إبطاء 0.5×، إعادة تشغيل. أزرار ≥ 44px، تسميات عربية، تركيز لوحة مفاتيح.
- `aria-label` عربي للـcanvas يصف التمرين الحالي، وبديل نصي لخطوات الحركة (يملؤه التطبيق).
- لا اعتماد على اللون وحده، وتباين AA للتسميات.

## 5) صفحة اختبار ثابتة للتسليم (مهمة جداً)
`mannequin_playground.html` مستقلة تُظهر: المجسّم، منزلقات لكل مفصل بحدوده (لأخذ الأوضاع بالعين وكتابتها كأرقام)، زر «انسخ الوضع كـJSON»، اختيار الثيم والبنية، تشغيل حركتين تجريبيتين (قرفصاء وبلانك) مكتوبتين بالواجهة أعلاه تثبتان أن الواجهة تكفي، وتفعيل `debug` يعرض الهيكل والحدود والتحذيرات.
